Hands-on with Exein Runtime for Zephyr on the nRF9151 and Deutsche Telekom nuSIM

nRF9151 Web Flasher

Flash the Electronica DT workshop firmware onto an nRF9151 DK straight from the browser: probe-rs compiled to WebAssembly, talking to the DK's onboard J-Link over WebUSB. Nothing to install. Source: exein-io/electronica-dt-workshop.

This page needs Chrome or Edge 137+ on Linux, macOS, Windows or Android. Tested on several Windows versions. If flashing fails: don't unplug or reset the board, click Flash again. Prefer Nordic's tools? nrfutil, step by step in the README.

01.Connect the J-Link

not connected

Close nRF Connect, nrfutil, J-Link tools and any other program using the probe first.

02.Choose the image and settings

none chosen

No token: fine for reflashing a board that is already registered. A new board needs one, otherwise it can't register and no incidents reach the platform.

If any of these is set, the flasher also writes a settings page at 0x80000. Empty fields keep the firmware's own value. The board registers with the token on its next boot (replacing any identity it already has) and then clears it; custom id and host stay until the next flash with settings. Needs firmware that reads the settings page (the workshop firmware does); other firmware ignores it. Watch the serial terminal for registered with the platform; token cleared.

03.Flash

nuSIM safe: the image is refused unless every byte lies below 0xF8000 (nuSIM storage and its UICR keys are never touched). Only the 4 KB sectors the image covers are erased; then everything is verified. MCUboot is only rewritten when it changed, and then last: if flashing fails, the board still boots and you can retry. If flashing fails: don't unplug, power off or reset the board, click Flash again (debug access closes at the next reset if the bootloader is gone).

The backup (0xF8000–0xFFFFF, read before anything is erased) holds this board's nuSIM data and goes to your browser's download folder (e.g. ~/Downloads): keep it private. It only helps on the same chip and only as long as its UICR key slots were never erased: after a recover / erase all the nuSIM can't decrypt it any more (see the README).

04.Serial terminal

closed

The board's UART through the J-Link's virtual COM port (pick the J-Link's first port), 115200 baud. Works while the board runs normally and next to flashing. With the workshop firmware you can type AT commands, e.g. AT%XICCID.
