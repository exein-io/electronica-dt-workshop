nRF9151 Web Flasher

Flash the Electronica DT workshop firmware onto an nRF9151 DK straight from the browser: probe-rs compiled to WebAssembly, talking to the DK's onboard J-Link over WebUSB. Nothing to install. Source: exein-io/electronica-dt-workshop.

Alternative route. The supported way to flash is local, with Nordic's tools (west flash / nrfutil, token via scripts/settings-hex.py), see the README. This page needs Chrome or Edge 137+ on Linux, macOS or Android. On Windows the SEGGER driver owns the J-Link and WebUSB can't open it.

2. Flash

If any of these is set, the flasher also writes a settings page at 0x80000. Empty fields keep the firmware's own value. The board registers with the token on its next boot (only if it has no identity yet) and then clears it; custom id and host stay until the next flash with settings. Needs firmware that reads the settings page (the workshop firmware does); other firmware ignores it.

nuSIM safe: the image is refused unless every byte lies below 0xF8000 (nuSIM storage and its UICR keys are never touched). Only the 4 KB sectors the image covers are erased; then everything is verified.

3. Register the board (once)

Enter the Exein Runtime token in step 2 and flash: the board registers itself with the platform on its next boot (watch it in the serial terminal: registered with the platform; token cleared). A board that already has an identity keeps it and ignores the token.

Serial terminal

closed

The board's UART through the J-Link's virtual COM port (pick the J-Link's first port), 115200 baud. Works while the board runs normally and next to flashing. With the workshop firmware you can type AT commands, e.g. AT%XICCID.
